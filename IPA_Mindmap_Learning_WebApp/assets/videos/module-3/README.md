# Module 3: import micro MP4 không cần sửa code

Đặt các video H.264/AAC vào **chính thư mục này** theo tên:

| Bài | Tên | Tính năng |
|---|---|---|
| 3.1 | `micro-01.mp4` | Tạo map / Central Topic |
| 3.2 | `micro-02.mp4` | Main Branch / Sub Branch |
| 3.3 | `micro-03.mp4` | Move / Restructure |
| 3.4 | `micro-04.mp4` | Relationship / label |
| 3.5 | `micro-05.mp4` | Visual Clarity |
| 3.6 | `micro-06.mp4` | Share / Export |

Có file mới -> commit/push GitHub -> refresh site. Không cần chỉnh mã nguồn.

Nếu dùng YouTube, tạo/tải `video-library.json` qua trang `video-setup.html` tại root project rồi upload vào `assets/videos/video-library.json`.

Nếu cần thay video bằng tệp trên 25 MiB, dùng GitHub Desktop/Git thay vì nút upload qua web GitHub.
