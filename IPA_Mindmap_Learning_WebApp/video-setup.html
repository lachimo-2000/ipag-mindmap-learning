Video Setup

Đối với video MP4, chỉ cần upload đúng tên tệp vào assets/videos/module-3/. Nếu muốn nhúng video YouTube, dán đường dẫn ở dưới và tải file cấu hình để đưa lên GitHub. Không cần sửa HTML/CSS/JavaScript.

Sau khi tải JSON

Vào GitHub repo → assets/videos/video-library.json → thay bằng file vừa tải → Commit. Các micro không có link YouTube sẽ tự đọc video MP4 tương ứng với tên micro-01.mp4 … micro-06.mp4. Không cần upload video từ trang này.
